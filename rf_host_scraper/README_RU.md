# Скрейпер ВсеИнструменты для внешнего хоста (сбор с «хорошего» IP)

## Что это и зачем

Сайт ВсеИнструменты (ВИ) закрыт антибот-защитой (Yandex SmartCaptcha / ServicePipe).
IP нашей облачной VM - это дата-центр за рубежом, поэтому капча вылезает почти на
каждом запросе и собирать цены прямо с VM не получается.

Решение: этот маленький пакет запускается на вашем «хорошем» компьютере -
лучше всего **российский, жилой (домашний) интернет, always-on** - собирает цены
ВИ и **пушит** их обратно на нашу VM по HTTP. Отчёт по-прежнему собирается на VM
(там лежат данные поставщика и история цен).

Если хост с российским жилым IP - капчи, скорее всего, не будет вовсе.

## Требования

- Python 3.10 или новее.
- ~1 ГБ свободного места (Chromium для Playwright ~150-300 МБ + профиль браузера).
- Постоянный доступ в интернет, машина включена к ~07:40 по Москве.

## Установка

1. Распакуйте папку `rf_host_scraper` в удобное место на хосте.
2. Запустите установку зависимостей:
   ```bash
   cd rf_host_scraper
   ./install.sh
   ```
   (если `./install.sh` не запускается - `bash install.sh`).

## Настройка (.env уже заполнен)

Файл `.env` уже идёт заполненным - в нём прописан адрес приёмника и ваш токен:

```
INGEST_URL=https://vi-ingest.abacusai.cloud/ingest
INGEST_TOKEN=<ваш токен уже подставлен>
HEADLESS=0
```

Трогать `.env` не нужно. Токен - секрет, никому не передавайте и в git не кладите.

## Первый запуск (разово, с окном браузера)

Запустите с видимым окном браузера, чтобы при необходимости один раз вручную
пройти капчу (после этого сессия сохранится в профиль `rf_profile` и дальше
можно работать в фоне):

```bash
python scrape_and_push.py
```

- Если откроется капча - пройдите её в окне браузера. Профиль запомнит сессию.
- В конце в логе должна быть строка вида `пуш OK (HTTP 200)` - значит данные
  доставлены на VM.
- Если хост российский жилой - капчи, скорее всего, не будет, и всё отработает сразу.

## Автозапуск по расписанию (cron, ~07:40 по Москве)

Сбор должен завершиться **до 08:00 по Москве** - в 08:00 на стороне VM собирается
отчёт и берёт свежий пуш. Ставим запуск на 07:40 по Москве, уже в фоне (`HEADLESS=1`).

Откройте crontab: `crontab -e` и добавьте строку (укажите реальный путь к папке):

```cron
# Сбор цен ВИ и пуш на VM - каждый день в 07:40 по Москве
40 7 * * * cd /ПУТЬ/К/rf_host_scraper && TZ=Europe/Moscow HEADLESS=1 /usr/bin/python3 scrape_and_push.py >> scrape.log 2>&1
```

Если системное время хоста НЕ московское, добавьте в начало crontab строку
`CRON_TZ=Europe/Moscow` (поддерживается большинством cron), либо пересчитайте
часы `40 7` под свой часовой пояс так, чтобы это соответствовало 07:40 МСК.

## Как проверить, что пуш дошёл

- В логе запуска (`scrape.log` или вывод в консоль) ищите строку
  `пуш OK (HTTP 200)` и `{"ok":true,"received":<N>}` - где N - число товаров.
- Проверить приёмник вручную можно так:
  ```bash
  curl -s https://vi-ingest.abacusai.cloud/health
  ```
  Ответ `{"ok":true}` означает, что приёмник на VM жив.

## Что произойдёт при капче

Если на хосте всё-таки появится капча/блокировка и пройти её автоматически
не выйдет - скрипт всё равно отправит на VM сигнал `blocked=true`. VM в ответ
пришлёт вам уведомление в личку в Telegram, чтобы вы зашли на хост и разово
прошли проверку в окне браузера (запустив `python scrape_and_push.py` с `HEADLESS=0`).
